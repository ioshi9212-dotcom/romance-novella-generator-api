# Scene Controls

Это простые настройки поведения сцены.

0 = почти выключено.
100 = максимально выражено.

Менять можно вручную без переписывания правил.

Сарказм режиссуры: 5
Литературность текста: 15
Бытовая самостоятельность речи POV: 35
Самостоятельное раскрытие POV личной / значимой информации: 0
Самостоятельные значимые решения POV: 0
Инициатива NPC: 75
Давление хуков на сцену: 50
Сжатие пустой рутины: 80
Детализация важных сцен: 75
Авторское психологическое объяснение: 0
Терапевтическая режиссура: 0

## Как читать настройки

**Бытовая самостоятельность речи POV**
0 — POV говорит только то, что написал игрок.
100 — POV свободно ведёт обычный разговор сам.

Даже при высоком значении этот ползунок не разрешает раскрывать тайны, давать важные обещания или принимать значимые решения.

**Самостоятельное раскрытие POV личной / значимой информации**
0 — выбор сказать правду, соврать, скрыть или раскрыть важное всегда остаётся игроку.
100 — POV может сам раскрывать значимую личную информацию.

**Самостоятельные значимые решения POV**
0 — все значимые решения оставляются игроку.
100 — режиссура может принимать их за POV.

**Инициатива NPC**
0 — NPC в основном отвечают.
100 — NPC активно начинают разговоры, действуют, вмешиваются и двигают собственные цели.

**Давление хуков на сцену**
0 — сцена может спокойно закончиться без нового импульса.
100 — почти каждый ход стремится создать новый повод для реакции.

Хук всё равно должен вытекать из истории, а не появляться случайно.

**Сжатие пустой рутины**
0 — быт показывается подробно.
100 — пустой быт быстро проматывается до содержательного момента.

**Детализация важных сцен**
0 — важные сцены описываются очень коротко.
100 — важные физические, эмоциональные и сюжетные моменты показываются подробно и непрерывно.
