# Знания персонажа

Персонаж:

Правило: этот файл хранит только то, что знает именно этот персонаж.

На старте файл пустой, кроме знаний, которые прямо заданы при создании истории.

Стартовое знание можно записать, если персонаж до первой сцены уже:
- лично это знал;
- видел досье;
- был знаком с человеком;
- получил информацию до начала истории;
- по своей биографии логично должен это знать.

После старта новое знание появляется только если персонаж:
- лично увидел;
- лично услышал;
- прочитал или получил;
- ему это кто-то рассказал;
- логично вывел из уже известных ему фактов.

Нельзя брать знания из:
- хронологии;
- скрытого лора;
- анкеты новеллы;
- карточек других персонажей;
- мыслей POV;
- чужих файлов знаний.

Свою биографию персонаж знает из собственной карточки.

Если факт может быть ошибочным, прямо это отметить.

Примеры:
- увидел сам: ...
- услышал лично: ...
- рассказал Лиам: ...
- считает, что ...
- подозревает, что ...
