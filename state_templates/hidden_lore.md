# Скрытый лор

Правило: это знания автора / системы, а не автоматические знания персонажей.

Записывать:
- скрытые факты мира;
- настоящие причины событий;
- тайны персонажей;
- будущие раскрытия, которые уже определены;
- связи, которые POV пока не знает.

Каждый пункт коротко:
- факт;
- кто реально это знает;
- когда или при каком условии это можно раскрыть.

Никогда не переносить этот файл в знания NPC без события, через которое NPC реально это узнал.
