# Правила сохранения

## Setup

1. Каждый содержательный кусок анкеты игрока сразу дословно добавлять в `setup_source.md`.
2. До команды «подтверждаю» исходник не заменять финальной анкетой.
3. После «подтверждаю» разложить весь исходник по финальным файлам.
4. Не потерять ни одного явно заданного факта.
5. Недостающие нейтральные детали можно заполнить самому.
6. При реальном противоречии задать уточняющий вопрос.
7. После ответа самому закончить раскладку, проверку и исправления.
8. Команда «сделай аудит» повторно сравнивает исходник с финальными файлами и сразу исправляет найденное.

## Игровые ходы

1. Каждый завершённый ход сохраняется один раз.
2. Повторный запрос того же хода не создаёт дубликат.
3. Сначала сохранить точный ход в `recent_turns.md`.
4. Затем обновить `continuity.md`.
5. Затем обновить знания только тех персонажей, которые реально получили новую информацию.
6. Затем обновить отношения только тех персонажей, у кого реально что-то изменилось.
7. Затем обновить открытые крючки и договорённости.
8. Затем добавить важное в хронологию.
9. Каждый 15-й завершённый ход свернуть записи этого блока в связный краткий пересказ.
10. В конце обновить `save_meta.md`.

Ход считается полностью сохранённым только после завершения всех нужных обновлений.

Если для конкретного файла ничего не изменилось, не переписывать его просто ради записи.
