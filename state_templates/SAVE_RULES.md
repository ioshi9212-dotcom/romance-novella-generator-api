# Правила сохранения

Правила должны оставаться короткими и буквальными.

## Setup

1. Каждый содержательный кусок анкеты игрока сразу дословно сохранять в `setup_source.md`.
2. Не исправлять, не сокращать и не пересказывать исходник.
3. До команды «подтверждаю» setup не считается готовым.
4. После «подтверждаю» разложить весь исходник по финальным файлам.
5. Ничего явно заданного игроком не менять.
6. Недостающие нейтральные детали можно заполнить самому.
7. После раскладки сверить финальные файлы с `setup_source.md`.
8. Команда «сделай аудит» повторяет эту сверку и сразу исправляет найденное.

## Игровые ходы

1. Каждый завершённый ход сохранять один раз.
2. Повтор того же хода не создаёт дубликат.
3. Точный текст последних 15 ходов хранить без пересказа.
4. `continuity.md` хранит текущее физическое состояние сцены и важные перемещения вещей.
5. Новое знание добавлять только конкретному персонажу. Старые знания не стирать.
6. Изменение отношений добавлять только затронутому персонажу. Старые причины изменений не стирать.
7. Открытые крючки и договорённости держать в `plot_threads.md`.
8. В хронологию добавлять только важное.
9. После каждых 15 ходов делать свёртку этого блока в 1–3 связных абзаца.
10. Новая свёртка добавляется к старым, а не заменяет их.
11. После сохранения обновить служебное состояние.

Если для файла ничего не изменилось, не придумывать обновление ради самого обновления.
