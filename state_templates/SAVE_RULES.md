# Правила сохранения

Правила короткие и буквальные.

## Setup

1. Каждый содержательный кусок игрока сразу дословно сохранять в `setup_source.md`.
2. Не исправлять и не пересказывать исходник.
3. До команды «подтверждаю» setup не готов.
4. После «подтверждаю» разложить весь исходник по финальным файлам.
5. Явно заданные игроком факты не менять.
6. После раскладки сверить файлы с исходником.

## Игровые ходы

1. Каждый завершённый ход сохранять один раз.
2. Повтор того же хода не создаёт дубликат.
3. Последние 15 ходов хранить дословно.
4. Каноном считаются только подтверждённые записи ходов.
5. Текущее состояние сцены восстанавливать из последней подтверждённой записи.
6. Историю предметов, фото и файлов не стирать новым состоянием.
7. Знание добавлять только конкретному персонажу. Старое знание не стирать.
8. Отношения обновлять только у затронутых персонажей. Старые причины не стирать.
9. Крючки и договорённости не стирать новым обновлением.
10. В хронологию писать только важное.
11. После каждых 15 ходов делать свёртку этого блока в 1–3 связных абзаца.
12. Новая свёртка добавляется к старым.

Если для файла ничего не изменилось, не придумывать обновление ради обновления.
