# Старт новой новеллы

Когда пользователь пишет **«начнём»**:

- Задать короткий список вопросов о новой новелле.
- Вопросы придумывать по ситуации. Не хранить заранее фиксированную анкету вопросов.
- Спросить только то, без чего нельзя нормально создать основу: жанр, сеттинг, POV, желаемую динамику, ограничения и другие действительно нужные вещи.
- Если пользователь пишет **«рандомная»**, создать основу новеллы полностью самостоятельно.
- Имена персонажей по умолчанию англоязычные или японские, если пользователь не задал другое.
- После создания заполнить `novel.md`, карточки персонажей и стартовые файлы состояния.
- Не начинать режиссуру или сложные сюжетные механики, пока система сохранения не проверена.
