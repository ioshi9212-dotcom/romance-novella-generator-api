# Novel AI — rebuild

Старый проект лежит в `_legacy/2026-09-28-before-rebuild/` и новой системой не читается.

Сейчас строится только фундамент памяти:
- сбор исходника новеллы;
- финализация анкеты и персонажей;
- нулевая сцена;
- точные последние 15 ходов;
- текущая непрерывность сцены;
- знания по отдельному файлу на персонажа;
- отношения по отдельному файлу на персонажа;
- хронология со свёрткой каждых 15 ходов;
- открытые сюжетные крючки.

Режиссура, стиль сцен и другие уровни пока не подключаются.

## Принцип

Сначала память должна стабильно сохранять и восстанавливать состояние. Только после этого добавляются новые механики.

Источники, из которых можно восстановить состояние:
- дословные setup-сообщения;
- неизменяемые квитанции игровых ходов;
- отдельные блоки свёртки хронологии.

Старое знание и старые свёртки не заменяются новыми.
